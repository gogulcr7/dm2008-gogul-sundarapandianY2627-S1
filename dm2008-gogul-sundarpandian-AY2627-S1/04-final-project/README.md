# Final Project — Title

3D Lantern Keeper

---

### The Project

this project is called lantern keeper. We tried to convert a 2D lantern keeper game into a 3D game. The player is a insect(bee) which emits light and survive a dark forest by dodging ghosts and consumes lanterns to keep its light from going to zero.
